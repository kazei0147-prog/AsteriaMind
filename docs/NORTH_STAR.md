## 一句话（永远不许被改掉）

> **我们在造一个能自己长大的认知体——不是被喂大的工具，不是给 LLM 套的壳。**
> 驾驶员在里头，机壳可以借、也可以造。

---

## 只有两个角色

| 角色 | 干什么 | 本质 | 能不能换 |
|------|--------|------|---------|
| **黑盒** | 负责「想」——自由联想、涌现、推理 | 借来的聪明（word2vec / 外部 LLM / 任意底座） | **能换**（热插拔 / 换更强壳） |
| **白盒** | 负责「看住」——锚外部真值、判真伪、留印记 | 我们自己的自我（记忆 / 法庭 / 宪法） | **不能丢**（换底座时整体转移） |

---

## 怎么配合（双生螺旋）

```
黑盒出主意 → 白盒把关（按外部真值 / held-out / 用户反馈判）
            → 过审的沉淀成「印记」
印记 → 养白盒自己（记忆 / 法庭 / 内部学习核）
     → 当下一代引擎的养料（换壳时的真实语料）
```

两条腿各走各的路，但互相喂料：**黑盒靠更强的引擎变强，白盒靠外部真值、用户反馈、越来越多的印记变强。**

---

## 红线（只有一条，不许突破）

> **法庭若以被审判者的产出为训练源，判决就不再是独立验证，而是循环论证 + 错误放大。**

工程表述：**同一黑盒权重，不接受同一白盒法庭的直接训练**——不把对当前输出的判词反向灌回正在被审的那台引擎。

这条红线防的是「自己骗自己」，**不是**要黑白盒互不相干。它们本质是双生螺旋。

---

## 名词对照表（那些年把我们绕晕的词）

| 你听到的词 | 其实就是 |
|-----------|---------|
| 热插拔 / 可换底座 | 黑盒（引擎）能换 |
| 外骨骼 / 治理层自我 | 引擎是借的，真自我（白盒+记忆+宪法）长在外面、跨底座存活 |
| 共生 / 双生螺旋 | 黑白盒互相喂料的配合关系 |
| cache-aside / 记忆短路 | 运行时：有印记直接出，没印记黑盒推理，白盒再记 |
| 印记 / 异步法庭审查 | 白盒记录前必过审、且后台异步做，防缓存中毒 |
| 内部自治学习核 / 自迭代核心 | 终点：长出自己的小引擎，黑盒退成机壳 |
| 法官非教材 | 红线那条：防循环论证 |

**以上全是同一个设计的侧面，不是一个东西的七个版本。**
