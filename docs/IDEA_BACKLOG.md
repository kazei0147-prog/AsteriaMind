# IDEA_BACKLOG — 提案登记册（防遗忘 · 生命周期管理）

> **为什么有这个文件**：开发中经常丢失以往提出的问题和方案（跨会话压缩丢失 / 决策散落在对话、memory、代码注释、文档四地 / 提案无生命周期状态）。
> **规则（协作纪律）**：
> 1. 讨论出新方案 → 当场入册（AI 主动登记，不等提醒）
> 2. 开始开发前 → 先查册，列出所有「确认」级待办
> 3. 实施完成 → 回填 commit + 验证方式
> 4. 每周回顾 → 捞「确认但两周未动」的提案提醒用户（防沉底）
>
> **状态定义**：🆕 提出 → 确认 / 搁置 → 实施中 → ✅ 已落地 / ❌ 否决（否决也留档，防重新发明轮子）
