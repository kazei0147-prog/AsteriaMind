# ID-026 · 可活动有向命名边（edge_promoter）

> 升级自 RADICAL_PARKING「可活动有向命名边」（用户 2026-08-24 提）。
> 状态：**实施中**（首轮 B→A 晋升 + 置信度校准已实跑真实库，生成路径 tier 优先化待重启生效）。
> 关联：ID-024（A/B 双层 + ArgumentGate）、ID-025（LLM 接入黑盒，本机制的外部算力源）。

## 一、核心意图

黑盒（co_text 共现 99.7%）的 abundance 要能**机制化地流向**白盒（命名边），且**非机械阈值**：
把"共现猜测→单命名边"的转化，包装成一个**生成任务**——模型自己定义关系（甚至提议新关系类型），像领任务；产物经 ArgumentGate 验证后才入白盒。

用户原话："不是机械式的，而是类似于深度指令一样，让模型自己去定义，就好像一个任务一样。"

## 二、2026-08-26 实测纠正（关键，避免重蹈 ID-024③ 锚设计错误）

首轮 B→A 晋升实测发现，原 ID-024③ 的四锚**对命名边几乎全饿死**：

| 锚 | 设计假设 | 实测 | 结论 |
|---|---|---|---|
| 锚1 用户确认≥3 | 用户常教 | 极少 | 稀疏，不可缩放 |
| 锚2 批判者熵<0.5 | critic 接好 | critic 未常态接线 |  starving |
| 锚3 co_text 共现能量≥0.3 | 共现佐证命名边 | **仅 29 条命中** | ❌ 设计错误：co_text 是**词元级**（"一个""我们"），命名边是**概念级**（"猫 IS_A 哺乳动物"），两端不重叠，共现根本佐证不了概念边 |
| 锚4 双向判读一致率≥0.7 | concept 接好 | concept 未常态接线 | starving |

**额外发现（决定方案走向）**：
- 31,554 条命名边中 **97.8%（30,852）是 `evidence_count=1` + `energy=0.0` 的一次性抽取**——从未被佐证、黑盒零能量，却标 `confidence=1.0`。**这是"胡言乱语"的真正源头**：单次噪声被当成确凿事实。
- 真正可靠的边很干净：**702 条 `evidence_count≥2` 且 `energy>0`**（如"动物 IS_A 生物"被抽 21 次、energy≈1.0）。
- 向量空间（word_vectors，128 维）可作锚，但：① 覆盖仅 2.3%（721/31554 两端都在词表）；② **对 CAN/能力类关系严重有偏**——"人类 CAN 使用工具"余弦 -0.208（明显真却判负）。仅适合 IS_A/OPPOSITE 等相似型关系。

**结论**：`重抽取频次`（evidence_count）才是命名边唯一可用的内部独立佐证信号；向量余弦只能作为相似型关系的辅助锚；**真正的"外部神谕"（用户确认/真实 API/ID-025 LLM 批判者）才是 tier A 的硬地板**——但稀缺，需异步积累。

## 三、可扩展关系注册表 `meta_relations`

把现在硬编码的 NAMED 集改成从库读取，让模型能提议新关系类型：

```
meta_relations(
  type TEXT PRIMARY KEY,        -- 关系类型, 如 IS_A / CAUSES / 模型新提议的 X
  definition TEXT,              -- 模型自定义的定义/理由
  proposer TEXT,                -- teach(用户) / model(自我提议) / seed(种子)
  status TEXT DEFAULT 'B',      -- B=候选(宽松) / A=已验证核心(外部锚)
  created_at REAL
)
```
- 模型在 edge_promoter 任务中可输出 `(关系类型, 方向, 理由)`，新类型先进 `meta_relations` 的 B 层。
- 验证逻辑复用 ArgumentGate（五要素论证强度 + 反证压制）。
- 验证 + 持久后，按 ID-024 的 B→A 路径晋升（必须重过外部锚）。

## 四、edge_promoter 任务（挂 offline_learner）

在 `offline_learner.py` 的任务循环里新增一种任务类型，与现有的 uncertain-edge / dream-hypothesis 并列：

1. **触发**：`co_text` 里**持久强共现**（多次出现、非一次性尖峰）且无命名边 → 晋升候选。
2. **生成（深度指令）**：evidence = {A, B, 共现强度, count, 上下文样本}。模型推断 `(关系类型 R, 方向, 理由)`，R 可从 `meta_relations` 选或**提议新类型**。
3. **验证**：候选 `(A,R,B,理由)` 过 ArgumentGate（论证强度 + 反证压制）。
4. **入白盒**：过闸 → `meta_relations`(B) + `directed_edges`(tier B)；达外部锚 → tier A。

**非机械性的保证**：关系标签是生成且被论证的（含可发明新类型），不是查阈值表。
