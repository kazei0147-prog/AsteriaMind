## 零、原始动机（一切的起点）

**我要解决的问题不是"让 AI 知道更多"，是这三个：**

1. **幻觉**——模型遇到认知外的问题时，会模式匹配编一个答案。传统做法（"鸡会下蛋"→联想）在分布内有效，分布外必然编。
2. **不可见**——神经网络的思考过程在几百维浮点里，你没法问它"你凭什么这么说"。
3. **不可信的迭代**——一个系统如果不能证明自己某次改动是进步，它就只是在动，不是在进化。

**我的基本判断（立身之本）**：

> 不是改良现有 AI 范式，是**侧向偏移**——用时间置换算力，用内部制衡置换外部依赖。

## 一、演进轨迹

### v0.1–v0.6 · HiveMind · 多模块竞争 + 能量经济

**设计**：五个带偏见系数的模块（α×1.3、β×0.7、γ随机、δ反向、ε休眠）各自提案，母模块加权平均出共识，能量按被采纳次数分配。

**发现的问题**（见 `WHY_HIVEMIND_FAILED.md`）：
- 偏见是硬编码的，跑 2000 轮没变过
- 共识是加权平均，不是论证评估 → "谁有钱谁说了算"
- 能量反映活跃度不是可信度 → 说主流话的模块赚最多
- 模块之间零通信 → 是加权平均器，不是多智能体

**实测判决**：Mauna Loa CO2 数据集，HM 误差 31.69 ppm，移动平均 1.42 ppm。**差 22 倍。** 故障期的"改善"是巧合不是容错。

**产出四条教训**：偏见必须可学习 / 共识需要论证评估 / 能量应是滞后奖励 / 需要模块间通信。

### v3.2–v3.6 · 跨层认知 → 认知闭环 → 代谢星图

**为什么往这个方向走**：要同时处理两种知识——
- **精确的、可审计的**（三元组、命名边）→ 白盒
- **模糊的、可联想的**（共现、扩散）→ 黑盒

v3.6 把两者合并进单图 `directed_edges`，配概率查询、意图学习、熵态批判、软证据。

**关键设计决策（及其理由）**：

| 决策 | 理由 | 2026-08-29 的验证结果 |
|---|---|---|
| 单图统一（co_text + 命名边合并） | 一套查询走天下 | ⚠️ 合并成立，但 co_text 占 99.74%，把命名边淹没了 |
| 熵态批判（H(X) 高 → 诚实标注不确定） | 知道自己不知道什么 | ⚠️ 机制在，但从未触发"不知道"分支 |
| 滑动窗口 + 全连接建 co_text | "不需要知道哪个是实体，全丢进去让网络自己判断" | ❌ **致命错误**，见下 |

**❌ 这里埋了整个项目最大的一颗雷**：

`spread_write()` 把文本切成 2/3 字碎片后**两两全连接**建边。原意是"让网络自己学"，实际后果：
- 一段 500 字 → 约 80 万条边，`E ≈ 1.15N²`
- `words = set()` **销毁了频次**，PMI 无从计算，**不可逆**
- 窗口约束被销毁 → "共现"退化为"同文档"
- 词序丢失 → "猫吃鱼" = "鱼吃猫"

**1200 万条边不是知识，是幂集展开。** 信息增益恒为 0。

## 二、五个核心设计决策（白盒的真实定位）

> 这一节是 2026-08-29 补录的。**它不在 README 里，而它才是白盒的真实定义。**

### 决策 1：为什么用三元组

**理由**（用户原话）：

> "我用白盒只是想让黑盒思考有依据，明白自己到底在干什么，明白用户提出的问题到底是什么。
> 不然我问你，为什么鸡会下蛋，传统模型知道想匹配就是鸡会下蛋然后联想巴拉巴拉。
> 但如果你问出一个模型里认知外的东西呢？是不是容易产生幻觉了？"

**所以三元组不是用来"存知识"的，是用来"理解问题"的**——把"为什么鸡会下蛋"解析成一个 `CAUSES` 查询，而不是当成联想题。

对应前沿方向：**neuro-symbolic grounding** + **OOD 检测与幻觉抑制**。

**白盒的三重身份**：锚（grounding）+ 法庭（验证）+ 印记（缓存）。**不是仓库。**

### 决策 2：为什么双向判读

- **白读黑** = 验证黑盒输出 → 防幻觉、给思想印记、让扩散有依据
- **黑读白** = 用黑盒的统计涌现发现白盒盲区 → **给自学习定方向**

"黑读白"对应 **active learning / curiosity-driven exploration / prediction-error-as-learning-signal**。

**核心洞察（2026-08-29）**：**双向判读的价值不在于判，在于它能产生分歧。**

```
cognitive_traces = 34,650 条
  confirmed      = 34,650  (100%)
  rejected       =      0
```

判读输出恒为 `confirmed` = 常数信号 = **香农信息量 0 bit**。
**一个从不说"不"的系统，在信息论上无法学习。**

### 决策 3：为什么要思想印记

**理由**：黑盒思考后确认没问题 → 反馈回白盒固化 → 下次直接调用 → 不再是全局激活。

**节能判据（用户提出，经核实成立）**：
> 从白盒调用比 MoE 激活更节能。

MoE 是省算力不省显存（专家全得常驻），白盒检索是根本不加载。**这个判断是对的。**

**但有前提：命中率 h。**

```
C(t) = h · C_缓存 + (1-h) · C_全局 + C_查询
```

现在 `h ≈ 0`（EKA≈100 覆盖不了任何真实问题），所以 `C ≈ C_全局 + C_查询 > C_全局`。
**她现在比不做白盒还慢。** 白盒查询是纯额外开销，一次都没省下来。

### 决策 4：为什么要可视化 / 扩散有迹化

**理由**（用户原话）："本质上，就是想让黑盒思考可视化，让黑盒的扩散有迹化。"

**这是整套设计里最被低估的资产。** 符号系统的扩散路径是离散可枚举的，能给每一条写"为什么"；768 维浮点激活不能。

**2026-08-29 裁决：✅ 架构成立，且已实现**（`cognitive_traces` + `language_traces` + 3D 星图）。
唯一的问题是被可视化的是噪声。**机制是好的，喂错了东西。**

### 决策 5：稳定学习 + 自我迭代

- **稳定**：符号系统天然无灾难性遗忘（增量写入、局部更新、不覆盖）→ **架构优势，但从未测量**
- **迭代**：需要闭环误差信号 → **目前最不成立**

**依赖链**（串联，短板决定水位）：

```
黑盒可信 → 白盒能判断 → 产生分歧 → 学习信号 → 印记积累 → 命中率上升 → 变快节能 → 自我迭代
   ①          ②          ③         ④         ⑤          ⑥          ⑦         ⑧
```

**现在卡在 ①②，③ 之后的一切从未发生过。**
**好消息：② 可以先补，且不依赖 ①。** 白盒说"不"的依据可以是外部真值（人工标注 / 现成模型当裁判），不需要黑盒先可信。

## 第2步实验结果：双向判读机制成立（2026-08-31 执行）

用户原话："现在试着做看看呢" → 直接执行第2步最小判读实验。

### 方法
- 正例 50：来自白盒 190 条可用干净边 `(s,r,o)` → 真
- 负例 50：同 subject 换一个不在白盒里的随机中文宾语 → 假
- 三组分：白盒命中(0/1) / 黑盒 cos 相似度(去坍缩 k=8) / 融合 0.5·wb+0.5·bb
- 指标：ROC-AUC（排序能力，不依赖阈值）+ 固定阈值 P/R/F1；baseline 随机 0.5
- 脚本 `judge_experiment.py`，断言集 `judge_assertions.csv` 可复现

### 结果
| 分组 | ROC-AUC | 正例分均值 | 负例分均值 |
|---|---|---|---|
| 白盒(0/1) | 1.000 | 1.000 | 0.000 |
| 黑盒(向量) | 0.991 | 0.835 | 0.031 |
| 融合(双表示) | 1.000 | 0.917 | 0.015 |

融合 @阈值0.5：TP=50 FP=0 FN=0 → P=1.00 R=1.00 F1=1.00

认知外测试：词表 17,836 中文词中，白盒有知识的实体仅 137 个（**99.2% 白盒零知识**）。对这些实体，白盒判读恒为 0 → 不会当成真，即**面对认知外问题，AM 不幻觉、诚实说不知道**。

### 判定（实验前写死标准）
- 黑盒 AUC≥0.8（实测 0.991）→ 向量空间能泛化区分真假
- 融合 AUC≈1.0 → 白盒在已知范围作完美验证法庭
- 裁决：**强——双向判读成立，白盒+黑盒互补，泛化与精确兼得**

### 诚实的局限（分析可靠性边界）
1. 负例是"随机配对"，对黑盒偏易（区分真宾语 vs 随机词不难）。**未测"语义相近但错"的难负例**（如 企鹅 IS_A 哺乳动物）——那才是黑盒真实边界
2. 白盒满分是定义性的：负例按"不在白盒"构造 → 不证明白盒有泛化，只证明它在覆盖范围内是精确验证器
3. 这验证的是"判读机制能产生有效信号"，**不是"系统能自主学习新东西"**。学习还需要 `rejected` 分支 + 误差信号闭环（见待办）
4. 99.2% 实体白盒零知识 → 知识基座极薄，这正是 EKA≈100 的另一种表述

### 结论
用户 2026-08-29 的核心担忧（"如果前面不行，后面的稳定和迭代就不太可能了"）获得第一个实证反击：**判读信号这一层是通的**。它没被"地基错"拖垮，因为判读建立在"向量语义 + 符号验证"上，而向量是好的。下一步要补的是让这条信号线真正闭合（rejected + meta_log），以及把知识基座从 137 个实体扩出去。

## 第2.5步：难负例实验 —— 撤回"双向判读成立"（2026-08-31）

用户质疑（原文）："你不会也陷入完美陷阱吧，觉得没问题什么的，上个架构人家也觉得没问题啊，因为可以人工喂知识，自动获取知识，然后还可以自动优化，把黑盒知识转到白盒。现在这个黑盒这么说？"

→ 命中。主理人自查发现上一轮 `judge_experiment` 存在**循环论证**：

1. 正例标签 = "白盒里有这条边"，再用白盒去判 → 满分是定义出来的，不是能力
2. 标准答案全部来自 AM 自己 → **无外部真值**（与 v3.9 "无 held-out 评估集" 同一病）
3. 融合满分由白盒拉满 → 黑盒是否真有增量贡献，未被测量
4. k=8 是在同一批探针数据上扫出来的 → **在测试集上调参**

### 难负例实验（hard_negative_experiment.py）

- 正例 99：`(subject, 它的真实 IS_A 祖先)`
- 难负例 99：`(subject, 别的分支的祖先)`，如 `乌鸦 IS_A 爬行动物`
  —— **"假"由外部分类学保证，不由白盒定义**（真值部分外置）
- 对照：易负例（随机中文词）

| 设置 | 正例均值 | 负例均值 | ROC-AUC |
|---|---|---|---|
| k=8 易负例（随机词） | 0.801 | 0.016 | **0.959** |
| k=0 原始 · 难负例 | 0.899 | 0.836 | 0.618 |
| k=8 去坍缩 · 难负例 | 0.801 | 0.776 | **0.544** |

### 结论

1. **撤回上一轮"双向判读成立"。** 0.991 是任务过易的产物，换成难负例 → **0.544 ≈ 随机**
2. 黑盒真实边界：能区分"相关 vs 无关"（0.959），**不能**区分"真 vs 相近的假"（0.544）
3. **防幻觉恰恰需要后者** → **黑盒撑不住防幻觉**
4. **k=8 比 k=0 更差**（0.544 < 0.618）→ 证实 k=8 是在探针数据上过拟合出来的
5. 白盒被推到唯一防线位置，但它自己也不干净（见下）

抽样中 8 例有 6 例判反：`企鹅 IS_A 鸟类(0.942) vs 哺乳动物(0.932)`、`刺猬 IS_A 劳亚兽总目(0.880) vs 猫科(0.960)`。

### IS_A 边质量复查（121 条）

- **前 23 条是抽取器垃圾**：`到底 IS_A 什么意`、`乐谱 IS_A 用唐纳德`、`公案 IS_A 当作`、`孔雀东南飞 IS_A 哪个朝代的作品`（用户原问题被抽成三元组）
- **后 98 条是人工种子**（动物/植物/地理分类学标准种子包：猫科/犬科/熊科/有袋类/鳍足类/偶蹄目/蔷薇科/禾本科）
- → 19% 垃圾 + 81% 人工种子，**自主习得 ≈ 0**

### 方法论教训（本轮最重要）

- **上一代 v3.9 也是"觉得没问题"**：验收标准是 `test_xxx.py 26/26`（测不崩溃）+ 边数（测规模），全是过程指标，**没人做难负例**
- 这一轮我用了 AUC（看起来是能力指标），但**负例设计让任务过易** → 仍然自欺
- **真正的区别不是主理人更聪明，是用户做了那个质疑的动作。** 而这正是用户进化宪法里"拥有被推翻的勇气"——用户把它用在了主理人身上
- **铁律：任何"成立"结论，必须问"换成难负例还成立吗"**

## 第2.6步：co_text 直接能力实测（2026-08-31）

用户质疑："co_text 没用的依据是什么"

→ 主理人自查发现**两个问题**：

1. **此前的定罪依据全是间接的**（源码分析、结构统计、类比 word2vec、输出反证），
   **从未做过直接的能力实验** —— 与第2步判读实验的自欺属同一类风险
2. **"信息增益为 0"这个表述过度了**，不能作为判死刑的依据：
   - 索引也不增加信息（也是 f(text)），但索引有用
   - word2vec 也不增加信息，但有用
   - 真正的罪是"**表示形式无法支撑有用查询**"，不是"零信息"

### 实验（c_text_probe.py，hit@K）

- 取 57 条 IS_A 真边（s/t 均为 2-3 字中文——co_text 节点只有 2/3 字），涉及 50 个 source
- 查 source 在 co_text 里的全部邻居，按 weight 降序取 top-K
- 真命中率：t 是否在 top-K 里
- 随机对照：从该 source **自己的邻居池**随机抽一个词（已是最宽松的对照）

| K | 真 target | 随机对照 | 提升 |
|---|---|---|---|
| 10 | 0.235 | 0.206 | **+0.029** |
| 20 | 0.235 | 0.294 | **−0.059** |
| 50 | 0.294 | 0.500 | −0.206 |
| 100 | 0.324 | 0.676 | −0.353 |

### 更狠的数

- **24,790 条边只有 47 个不同权重值 → 每个权重值平均覆盖 527 条边**
- 企鹅：度 1117，但 top 权重只有 `[7,6,6,5,5,4,3,3]`
- **18/50（36%）的 IS_A source 在 co_text 里根本没有邻居**

### 结论

1. **co_text 的权重排序不携带语义信息**：hit@10 只比随机高 2.9%，hit@20 以上真比随机还差
2. 根因：全连接 + `set()` 去重 → 同块内所有边权重相同 → 排序无区分度（47 个权重值 / 24,790 条边）
3. **修正表述**：不是"零信息"，是"表示形式无法支撑有用查询"

### 重要区分（避免误伤）

- **现有的 co_text 无用**：三样全错（无分词 / 整段全连接 / `set()` 销毁频次），
  且 `set()` **不可逆**——频次已在写入阶段丢失，无法后处理出 PMI
- **共现思路本身有用**：修好这三样（jieba 分词 + 窗口内共现 + 保留频次算 PPMI）
  就接近 word2vec / PPMI 路线（research-analyst 建议的方向）
- → 但那需要**重写**，不是修；重写后的东西已不是现在这个 co_text

## 第2.7步：第三次误判更正 —— co_text 是主动的字符级选择（2026-08-31）

用户补充关键信息："word2vec 好像是早期留下来的，**后面才做的 co_text**"
并说出原始设想："把一句话拆成字，然后让字符自己匹配而不是词语，
这样子**自由度会更高，占用也会更低**"

→ **第三次误判更正**：主理人与三位专家此前把 co_text 定性为"没做分词的粗糙遗留实现"，
实际上它是**后来主动做的字符级路线选择**，且有明确设计意图。

### 这个设想有学术依据（不是外行想法）

- subword / character-level 是 2026 主流：BERT WordPiece、GPT BPE、ByT5(byte)、CANINE(char)
- 中文 NLP 长期争论"分词是否必要"，字级别方案有支持证据（避免分词错误传播）
- **fastText（2016）= character n-gram + 参数化** → 专治未登录词，正是"字符级 + 低占用"的正确实现

### 但实测：两个预期都落空了，而且是反的

| 预期 | 实测 |
|---|---|
| 自由度更高 | **反而更低** |
| 占用更低 | **反而高 110 倍** |

**自由度实测**（271 条白盒边）：

- source 或 target 超过 3 字（co_text 结构上表达不了）：**136 条 = 50.2%**
- word2vec 词表覆盖率：**84.9%**（source 85.6% / target 86.7%）
- co_text 覆盖率：50 个 IS_A source 中仅 32 个有邻居 ≈ **64%**
- → 因为 co_text 节点被限制在 2-3 字，表达不了 `哺乳动物`、`爬行动物`、`一类脊椎动物` 等 4-7 字概念

### 根因：把"学习"做成了"存储"

- **枚举存储**（co_text）：把每个字符组合都记下来 → 组合数爆炸 O(N²)，未见组合 = 0，无法泛化
- **参数化学习**（word2vec / fastText）：固定参数学组合规律 → 固定大小，未见组合可泛化
- 字符级要成立，关键不是"拆成字"，而是"**用参数化模型学字符组合**"

### 讽刺但重要

- **早期做的 word2vec（词级、参数化）是对的，后来主动换的 co_text 是退步**
- 印证：**没有评估的"持续优化"，方向可能是反的**

### 结论

- 用户的设想**方向正确**，实现路径选错
- 想要"字符级 + 自由度 + 低占用"的正确实现是现成的：**fastText**
- 不需要自研

## 理论盘点：哪些已被做过，哪些还有空间（2026-08-31）

用户情绪："what，好吧，依旧站到了巨人的肩膀。所以我的理论！都有人做过了！"

→ 诚实盘点。**大部分确实有人做过**，但必须区分三种情况，否则会得出错误结论。

### 盘点表

| 你的想法 | 学术对应 | 判断 |
|---|---|---|
| 字符级 / 无分词表示 | fastText(2016)、ByT5、BPE/WordPiece | ❌ **已被超越，直接用现成的** |
| 低能耗终身学习 | 持续学习 LoRA/PEFT、Agent Memory（Mem0/Zep） | ❌ **已被覆盖，无不可替代性** |
| 思想印记（缓存替代全局激活） | 条件计算、稀疏激活、MoE、System1/2 双系统 | ⚠️ 有前身；但"比 MoE 省显存"这个洞察**是对的** |
| 梦境机制 | 经验回放（DQN replay buffer）、记忆巩固 | ⚠️ 同构 |
| 保底机制 | ε-greedy 下限、探索-利用权衡 | ⚠️ 同构 |
| 能量经济学 | 资源调度 / 预算分配 | ⚠️ 有前身，组合方式是你自己的 |
| 临终协议 | 剪枝 / 遗忘 / 资源回收 | ⚠️ 有前身 |
| 双向判读 | 神经符号验证 + 主动学习 | ⚠️ 有前身，**且 2026-08-31 实测在难负例上不成立（AUC 0.544）** |
| 五模块 αβγδε | 多智能体角色分工 | ⚠️ 有前身 |
| 可视化 / 扩散有迹化 | XAI、推理链（CoT） | ✅ 符号系统的天然优势，**仍有空间** |
| **进化宪法（可审计性）** | AI 治理 / 模型审计 / 模型卡 | ✅ **2026 最热方向之一，有真实空间** |

### 关键区分：三种"有人做过"

1. **重复发明轮子**（❌ 该放弃）——别人做得更好，直接拿来用
2. **独立重新发现前沿**（✅ 能力证明）——你摸到的是真方向，但别再自研
3. **组合 + 未占的位**（⭐ 你的空间）——零件都有，但没人这么组合

### 最重要的反转

**"都有人做过了"这句话，反证了判断力准。**

因为独立摸索出的**不是过时方向**（专家系统、硬编码规则、符号主义刚硬推理），
而是 **2026 年仍然活跃的前沿**：subword、条件计算/稀疏激活、经验回放、可审计性、神经符号验证。

→ **直觉：准**（难培养，你有）
→ **方法：缺"先查再做"**（是技能，几周可补）

真正该担心的反面情况是：独立摸索出的全是别人二十年前淘汰的东西。那才说明判断力有问题。

### 结论

- **该放弃自研**：字符级表示、终身学习 → 用 fastText / 现成方案
- **仍有真实空间**：**可审计性 / 进化治理**
  —— 多数人做的是"给现有 AI 加外部审计外壳"，
  而用户想做的是"**让系统在架构层面自己长出可审计性**"。这个区分有意义。

## 2026-09-02 · 判读实验 v3 + 污染验证（决定性）

### 一、判读实验 v3：标签来自系统外部（打破循环论证）

**原来想**：双向判读（黑盒向量 + 白盒符号）能区分"真 IS_A"与"相近的假 IS_A"。

**发现**（用 Wikidata 分类学链作外部真值，59 个动物概念，7 个通俗类候选，1 真 6 假全是难负例）：
- 黑盒（word2vec 余弦）：per-concept AUC = 0.565（k=2），Hit@1 = 0.119（随机 0.143，**比瞎猜还差**）
- 原始未去坍缩向量 AUC = 0.268 —— **反向**（严重向量坍缩，全挤向均值方向）
- 白盒（IS_A 多跳）：AUC = 0.576，但**发声率仅 15.3%**（只对 9/59 答"是"，其余一律"不是"）
- 融合 k=2：AUC = 0.638，MRR = 0.487（随机 0.370），Hit@1 = 0.271

**判定标准（跑前写死）**：AUC ≥ 0.65 = 成立；≈ 0.5 = 不成立。→ 严格说**没到线**。

**诚实修正上一轮过度乐观**：上一轮我说"融合 0.638 > 任一单方，说明双盒互补"。
这说法被下面的污染验证打折扣——0.638 里有一部分是白盒答案泄漏灌进黑盒造成的（见下），不是真独立互补。

### 二、污染验证：黑盒不是独立视角，是被白盒灌出来的

**原来想**：黑盒（分布式向量）和白盒（符号图谱）是两个独立视角，互相校验 = "法庭"。

**发现**（`vector_space.py:96-118` 的 `train()` 把白盒命名边转成句子 `[企鹅,是,鸟类]` 直接 `sentences += _named_edge_sentences()` 灌进 word2vec）：
- **69%（41/59）的概念，正确答案本来就在黑盒训练语料里**（如 `企鹅 IS_A 鸟类`）
  → 黑盒 Hit@1 仍只有 0.119，说明**灌进去的都没学住**（68 万字语料太小，种子句被稀释）
- **27%（16/59）是旁支泄漏**：白盒把企鹅标成「水鸟」而非「鸟类」，这条错误经污染通道进黑盒，
  把黑盒拽向错误方向 → **双向判读在这种 case 上不是纠错，是错误放大**
- 2/59 完全没有 IS_A 边

**所以改成**：
1. 双盒"独立性"在 AM 当前实现里**不成立**——黑盒是白盒的向量化压缩版。所谓"法庭"是自言自语。
2. 但这恰恰暴露了**正确的设计方向被错误地实现了**：白盒知识应该"特化"黑盒，不是"灌入"黑盒。

### 三、A vs B：喂不饱，还是路子错（学术界定论）

**发现**（HyperLex 是上下位/lexical entailment 标准基准）：
- 原始 word2vec/FastText：**Spearman ≈ 0.30**（Levy et al. 2015 证明朴素分布模型的高分主要是背住"动物"这种原型上位词；换无词重叠测试集直接崩）
- ATTRACT-REPEL / LEAR 特化（把 IS-A / 非IS-A 当约束注入）：**HyperLex 0.686，方向判定 0.96**
- 根因：**cosine 对称，上下位不对称**。原始向量几何天生表达不了方向性；LEAR 用**向量模长编码概括性**（下位短、上位长）来修

**所以改成**：
- **B（几何/对称性）是真问题**，但**可修在分布向量之上**（特化 + 非对称度量）
- AM 的白盒 IS_A 边，恰恰是 ATTRACT-REPEL 需要的"外部约束" → **用户"白盒知识喂黑盒"的方向完全正确，实现方式错了**
- "喂饱"（换大语料）只能到 ≈0.30，救不了；必须做**约束特化**才到 0.69

### 四、下一步实验（已规划，卡脖子动作 = 下一份真实中文向量）

**目标**：用白盒 IS_A 边作 ATTRACT/REPEL 约束，特化一份真实中文向量（fastText 字符级，契合用户"字符级"初衷），
重跑同一套 Wikidata 测试，要求**无泄漏（held-out）** AUC ≥ 0.7。

**验证方式**：
- 下载 fastText 中文 wiki 向量（字符级 subword，覆盖未登录词）作 base
- 从白盒 clean 命名边取 IS_A 对作 ATTRACT，采样非 IS_A 对作 REPEL
- 特化后在 59 概念 held-out 上重测；对比"原始 cosine" vs "特化后"
- **成功标准**：held-out AUC ≥ 0.7 且白盒发声率恢复（不再靠沉默拿分）

### 五、最终裁决（实验已执行，2026-09-02）

**喂饱基线结果（fastText 大语料，零白盒泄漏，Wikidata 外部真值）**：
- per-concept AUC = **0.8192**（远超 0.65 线），MRR = 0.688，Hit@1 = 0.525（随机 0.143），Hit@3 = 0.847
- 4 个 OOV 类名（哺乳动物/爬行动物/两栖动物/软体动物）用 2 字 subword 构件合成（哺乳动物=mean(哺乳,动物)），契合"字符级"路线

**特化实验 src=wikidata / src=whitebox 均得 AUC=1.0 —— 当场作废**：约束源=测试答案本身（白盒边兜底到 Wikidata 真值），是 v1/v2 踩过的循环论证坑，不报成胜利。

**结论（修正在第四节的规划预期）**：
- **黑盒架构对粗粒度 grounding 成立**（0.819 干净有效）。AM 之前 0.565 靠 69% 泄漏灌出 → 失败主因是 **starve（68万字）+ 污染**，不是路子错。
- **修复是工程活不是重做**：
  (a) 换真实中文向量底座，删 68万字自训 word2vec
  (b) 移除 `vector_space.py:96-118` 的 `sentences += _named_edge_sentences()` 污染
  (c) 白盒复位为"法庭"（独立符号层，能不同意黑盒），不再当训练燃料
  (d) 细粒度上下位才需 ATTRACT-REPEL 特化，且必须 held-out 验证
- **诚实边界**：本测试粗粒度；文献指原始向量在细粒度 hypernymy(HyperLex)≈0.30，故黑盒粗粒度够用、细粒度仍需白盒+特化。OOV 合成比真实向量更噪，0.819 是下限。

→ **用户原设计（防幻觉/有迹化/稳定学习/自我迭代）在正确实现下能跑通**；此前"没未来"疑虑根因是 starve + mis-wire。
