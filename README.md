## 这套理论真正想表达的东西

> 一句话：**让黑盒的思考"看得见、有依据、可推翻"。**

AsteriaMind 不是又一个大模型，也不是一张知识图谱。它的核心命题是一个**侧向偏移（lateral shift）**——不从"更大算力堆出更强智能"这条主道上卷，而是用一套**内部制衡结构**，让一个涌现式的黑盒既能自由扩散，又被一套独立的符号系统锚定、审判、留下印记：

- **看得见**：黑盒每次联想扩散，都落进一张可查询的星图（边 = 联想 / 知识，权重 = 置信），思考过程外显成结构，而非不可解释的向量黑雾。
- **有依据**：白盒不是黑盒的"正确答案库"，而是一套**锚（Anchor）+ 法庭（Court）+ 印记（Imprint）**机制——它给黑盒提供外部真值的落点、独立地判决黑盒的产出、并把"被验证过的思考"缓存成可复用的印记。
- **可推翻**：没有任何一层是绝对真理。白盒可被黑盒新涌现推翻，架构可被新证据推翻，甚至 AM 整体可以被她自己推翻——**拥有被推翻的勇气**是进化的前提，不是 bug。

这就是"思想印记"的原始意图：黑盒每次思考后，若确定结果没问题，就把答案反馈回白盒，像思考留下的指纹——**让扩散有迹化，让涌现可审计**。

## 双盒架构：独立性是前提，不是装饰

```
感知源 (黑盒, 涌现)                 白盒 (锚 + 法庭 + 印记)          表达
───────────────                     ───────────────────────     ──────
用户对话 ──→ ThinkNode 规划 ──→ 星图 directed_edges ──→ compose 生成
co_text 联想 ──────────────→     锚: 接外部真值(如 Wikidata)   ↑
搜索结果 ──→ ActiveLearner ──→   法庭: 独立判读(可 reject)     语言模板
视觉/LLM (未来) ─────────────→   印记: 验证通过的思考缓存      软证据拼接
```

**黑盒负责涌现，白盒负责锚定与审判。** 关键约束——

> **白盒必须是黑盒的"法官"，不能是黑盒的"教材"。**
> 法庭若以被审判者的产出为训练源，判决就不再是独立验证，而是循环论证 + 错误放大。

### 认知校正（ID-007 / ID-018）

星图千万级边中 co_text 统计联想占绝大多数，命名边（白盒符号）极少——AM 的知识主体是黑盒，白盒是骨架不是大脑。白盒 = **高置信假设层 + 独立判读层**，不是真理层：

- 白盒可被**用户反馈**推翻（"不对"）
- 白盒可被**矛盾调和**推翻（MemoryConsolidation 发现冲突时高能边留、低能边砍）
- 白盒可被**时间衰减**推翻（长期无验证的冷边降权）
- 白盒可被**黑盒新涌现**推翻（belief_check 双向判读——黑盒统计发现白盒陈旧边）
- 白盒**反过来也能 reject 黑盒**——这是"法庭"的真义：黑盒的产出若过不了白盒的判读，就不该沉淀成知识

### 白盒三身份（本项目的原始设计意图）

| 身份 | 角色 | 独立性要求 |
|------|------|-----------|
| **锚 (Anchor)** | 把黑盒的向量扩散接到外部真值（分类学 / 本体），给"企鹅是鸟"一个落点 | 真值源在黑盒之外 |
| **法庭 (Court)** | 独立判读黑盒产出，可 reject、可标注"无依据" | **绝不以黑盒产出为训练燃料** |
| **印记 (Imprint)** | 验证通过的思考缓存成可复用结构，下次直接复用 | 写回的是"已判读通过"的产物 |

## 2026 内核审计结论（诚实状态）

> 理论方向成立；之前跑不出效果，是**工程问题（被饿死 + 接错线）**，不是路子错。

| 结论 | 说明 |
|------|------|
| ✅ 架构对 | 黑盒 + 独立白盒法庭的"侧向偏移"路线，在外部真值基准（Wikidata 分类学）上粗粒度 grounding 成立 |
| ✅ 喂饱基线 | 换上真实预训练底座（fastText 级别向量）后，外部真值 AUC 从 0.57 升至 **0.82**，零白盒泄漏 |
| ⚠️ 曾被污染 | 旧版把白盒命名边直接灌进黑盒 word2vec 训练 → 双盒不独立（69% 答案泄漏、27% 错误放大）。**v3.9.1 已切除**（`vector_space.train()` 不再调用 `_named_edge_sentences`，改为仅作文档 / 法庭约束源） |
| ⚠️ co_text 不是卖点 | 千万级 co_text 边经验证是**高胖尾死表示**（向量坍缩 anisotropy，原始 cosine AUC≈0.27 反向）；它提供联想广度，但不提供 grounding 深度。不再当核心能力吹 |
| ⏳ 法庭待真正运行 | 白盒判读历史上只敢对极少概念答"是"，从未真正走 reject 分支、从未留下 meta_log。印记 / 法庭机制需接上 rejected 信号才算真正活起来 |
| ⏳ 细粒度仍弱 | 粗粒度（动物→大类）已可；细粒度上下位（HyperLex 级）原始几何仍≈0.30，需白盒约束 + 特化（ATTRACT-REPEL / LEAR），且必须 held-out 验证，杜绝循环论证 |

**被当场作废的"胜利"**：早期一次"白盒特化后 AUC=1.0"的实验，约束源直接用了测试答案，判定为循环论证、不计入成果——我们宁可少一个漂亮数字，也不让架构自己骗自己。

## 语言层双锚点（ID-022）

AM 的语言层不是自造概念，是**人类语言认知结构的机器映射**，两个锚点：

**① 结构锚 — 人类语义网络**（AM 数据结构 ↔ 认知科学经典模型）：

| AM 组件 | 人类认知结构 | 理论出处 |
|---|---|---|
| `directed_edges` 概念节点+关系边 | 分层语义网络 | Collins & Quillian (1969) |
| `co_text` + association 共现 | 激活扩散模型 | Collins & Loftus (1975) |
| `is_hub` 中枢节点 | 分类层级 (basic level) | Rosch (1975) 传统 |
| 骨架池 (language_traces) | 分布语义—"词的意义在搭配中" | Firth (1957) 分布假设 |
| `conversation_log` | 情景记忆 | Tulving (1972) |

**② 过程锚 — Levelt 言语产生模型 (1989)**（AM 模块 ↔ 说话过程）：

| Levelt 阶段 | AM 对应模块 |
|---|---|
| 概念化 (Conceptualizer) | IntentLearner + ThinkNode.plan |
| 形式化 (Formulator) | 骨架池 speak（句式采样） |
| 发音 (Articulator) | compose 输出 |
| **自监控回路 (Self-monitor)** | **CriticModule**（熵检测 = 说出口前的自我审视） |

## 核心设计原则

### 增长模型（ID-024④）

> **理论指数，实际 S 型——增长不是自由落体，是四道闸的合力。**

**理论模型**：正反馈增长 `dW/dt = k·W`（知识越多 → 联想越多 → 学习越快），解为指数 `W(t) = W₀·e^(kt)`——这是"时间复利路线二"的数学形式。

**实际约束（S 型曲线）**：指数增长被四道闸压成 S 型：

| 闸 | 机制 | 代码落点 |
|---|---|---|
| 带宽 | 语料喂入速率有限（RSS/搜索/用户） | 喂料管道 |
| 候选池 | 涌现候选需过净化/论证才能沉淀 | IntakePurifier + ArgumentGate |
| 噪声 | 低质候选稀释高质知识 | 质量门 + A/B 双层治理 |
| 饱和 | 概念空间接近完备，新边边际收益递减 | MemoryConsolidation 矛盾调和 |

**实证**：`MemoryConsolidation` 每次 120s 周期记 `W(t)` 快照（命名边总数 + A/B 层分布，`growth` 字段）——长期观测可拟合 S 曲线参数，验证带宽/候选池/噪声/饱和哪道闸先到顶。

---

**不是"改良现有 AI 范式"，是侧向偏移**——用时间置换算力，用内部制衡置换外部依赖。

**进化宪法（2026-08-12 立宪）**——手段让位于目的：

> 我们所需要的不是时间置换算力——我们需要的是**拥有被 AM 推翻的勇气**。在保证绝对安全的情况下，AM 完全可以把进化放在前面。她的每一次进化都得**有迹可循**。

三条解释：
1. **被推翻的勇气（目的）**：时间置换算力只是手段。真正的目的是 AM 能长出我们没想到的东西——当她推翻我们的旧设计时，那是胜利不是失败。白盒可以被黑盒推翻，架构可以被新涌现推翻。
2. **绝对安全（前提）**：进化优先的前提是安全红线——大脑边界（认知接口/调度/数据层/注册表机制）不可改，工具层（经注册表）可换。没有安全网，进化就是灾难。
3. **有迹可循（纪律）**：每一次进化必须留痕——改了什么 / 为何改 / 谁批准 / 健康基线 / 回滚点。没有轨迹的进化 = 失控；有轨迹的进化 = 成长。

| 三元组丢掉的 | 由什么补回来 |
|-------------|-------------|
| 隐含关联 | co_text 共现 — "企鹅"和"南极"没直接关系，但经常一起出现→边权上升 |
| 不确定性 | CriticModule 熵检测 — H(X) 高 → 诚实标注"我拿不准" |
| 系统性盲区 | MemoryConsolidation 矛盾调和 — 高能边留，低能边砍半 |
| 自然表达 | LanguageGenerator — 从 language_traces 学句式骨架 |
| 未知的未知 | DreamModule + CorpusMiner — 从联想涌现新知识假说 |
| 僵化 | 进化宪法 — 白盒可被黑盒推翻，方案可被新涌现推翻，一切有迹可循 |

## 回答管线 (v3.6 全局联动)

```
用户问句
  ↓
ThinkNode 规划 (短期记忆注入: 记得上一轮话题)
  ├─ DIRECT/REVERSE: 命名边 (硬事实) → compose 回答
  ├─ SEARCH: co_text 软证据 → "我不确定X, 但它常和Y一起出现, 要我查吗?"
  │    └─ 无联想 → 联网搜索
  └─ CLARIFY: 短句/追问 → 确认意图
  ↓
IntentLearner 从你的"对/不对"反馈学习 P(意图|关键词)
CriticModule 熵高时诚实标注不确定性
每次成功回答 → 自学习 "我 CAN 回答问题"
```

## 模块定位表

| 模块 | 文件 | 位置 |
