## 架构总览

```
感知源 (黑盒, 涌现)                    白盒筛选 (显微镜+闸门)         表达
───────────────                     ─────────────────         ──────
用户对话 ──→ ThinkNode 规划 ──→ 星图 directed_edges ──→ compose 生成
co_text 联想 ──────────────→      (597万边: 命名+联想)     ↑
搜索结果 ──→ ActiveLearner ──→   ↑                      语言模板
视觉/LLM (未来) ─────────────→  CriticModule 熵检测       软证据拼接
                               MemoryConsolidation 矛盾调和
                               IntentLearner 意图统计
                               CorpusMiner 语料挖掘
```

**黑盒负责涌现，白盒负责筛选** — 所有感知源产出"候选"，只有验证过的才沉淀为星图边。

### 认知校正（ID-007，2026-08-12 讨论 · 2026-08-20 落 README）

> **黑盒是引擎，白盒是显微镜 + 闸门——不是"唯一真相源"。**

星图 1100 万+ 边中 co_text 统计联想占 **99.7%**，命名边（白盒符号）仅 **0.3%**——AM 的知识主体是黑盒，白盒是骨架不是大脑。白盒 = **高置信假设层**，不是真理层：

- 白盒可被**用户反馈**推翻（"不对"）
- 白盒可被**矛盾调和**推翻（MemoryConsolidation 发现冲突时高能边留、低能边砍）
- 白盒可被**时间衰减**推翻（长期无验证的冷边降权）
- 白盒可被**黑盒新涌现**推翻（ID-018 belief_check 双向判读——黑盒统计发现白盒陈旧边）

白盒介入力度按 **L0-L4 谱系**分级（观察 / 提示 / 拦截 / 修复 / 禁止），防介入过激闷死涌现（ID-008，HealthMonitor 驱动）。

### 语言层双锚点（ID-022，2026-08-15 讨论 · 2026-08-20 落 README）

AM 的语言层不是自造概念，是**人类语言认知结构的机器映射**，两个锚点：

**① 结构锚 — 人类语义网络**（AM 数据结构 ↔ 认知科学经典模型）：

| AM 组件 | 人类认知结构 | 理论出处 |
|---|---|---|
| `directed_edges` 概念节点+关系边 | 分层语义网络 | Collins & Quillian (1969) |
| `co_text` + association 共现 | 激活扩散模型 | Collins & Loftus (1975) |
| `is_hub` 中枢节点 | 分类层级 (basic level) | Rosch (1975) 传统 |
| 骨架池 (language_traces) | 分布语义—"词的意义在搭配中" | Firth (1957) 分布假设 |
| `conversation_log` | 情景记忆 | Tulving (1972) |

**② 过程锚 — Levelt 言语产生模型 (1989)**（AM 模块 ↔ 说话过程）：

| Levelt 阶段 | AM 对应模块 |
|---|---|
| 概念化 (Conceptualizer) | IntentLearner + ThinkNode.plan |
| 形式化 (Formulator) | 骨架池 speak（句式采样） |
| 发音 (Articulator) | compose 输出 |
| **自监控回路 (Self-monitor)** | **CriticModule**（熵检测 = 说出口前的自我审视） |

## 核心设计原则

**不是"改良现有 AI 范式"，是侧向偏移**——用时间置换算力，用内部制衡置换外部依赖。

**进化宪法（2026-08-12 立宪）**——手段让位于目的：

> 我们所需要的不是时间置换算力——我们需要的是**拥有被 AM 推翻的勇气**。在保证绝对安全的情况下，AM 完全可以把进化放在前面。她的每一次进化都得**有迹可循**。

三条解释：
1. **被推翻的勇气（目的）**：时间置换算力只是手段。真正的目的是 AM 能长出我们没想到的东西——当她推翻我们的旧设计时，那是胜利不是失败。白盒可以被黑盒推翻，架构可以被新涌现推翻。
2. **绝对安全（前提）**：进化优先的前提是安全红线——大脑边界（认知接口/调度/数据层/注册表机制）不可改，工具层（经注册表）可换。没有安全网，进化就是灾难。
3. **有迹可循（纪律）**：每一次进化必须留痕——改了什么 / 为何改 / 谁批准 / 健康基线 / 回滚点。没有轨迹的进化 = 失控；有轨迹的进化 = 成长。

| 三元组丢掉的 | 由什么补回来 |
|-------------|-------------|
| 隐含关联 | co_text 共现 — "企鹅"和"南极"没直接关系，但经常一起出现→边权上升 |
| 不确定性 | CriticModule 熵检测 — H(X) 高 → 诚实标注"我拿不准" |
| 系统性盲区 | MemoryConsolidation 矛盾调和 — 高能边留，低能边砍半 |
| 自然表达 | LanguageGenerator — 从 language_traces 学句式骨架 |
| 未知的未知 | DreamModule + CorpusMiner — 从联想涌现新知识假说 |
| 僵化 | 进化宪法 — 白盒可被黑盒推翻，方案可被新涌现推翻，一切有迹可循 |

## 回答管线 (v3.6 全局联动)

```
用户问句
  ↓
ThinkNode 规划 (短期记忆注入: 记得上一轮话题)
  ├─ DIRECT/REVERSE: 命名边 (硬事实) → compose 回答
  ├─ SEARCH: co_text 软证据 → "我不确定X, 但它常和Y一起出现, 要我查吗?"
  │    └─ 无联想 → 联网搜索
  └─ CLARIFY: 短句/追问 → 确认意图
  ↓
IntentLearner 从你的"对/不对"反馈学习 P(意图|关键词)
CriticModule 熵高时诚实标注不确定性
每次成功回答 → 自学习 "我 CAN 回答问题"
```

## 模块定位表

| 模块 | 文件 | 位置 |
|------|------|------|
| **CognitiveStarMap** | `cognitive_star_map.py` | 单图世界模型 — 597万边统一存储 + 概率查询 |
| **ThinkNode** | `think_node.py` | 问题规划 — 主语提取 + 策略路由 + co_text 联想 |
| **IntentLearner** | `intent_learner.py` | 意图学习 — 从反馈学 P(意图\|关键词)，正则当先验 |
| **CriticModule** | `critic_module.py` | 熵态批判 — H(X) 高熵 → 诚实标注不确定性 |
| **CorpusMiner** | `corpus_miner.py` | 语料矿工 — 文本 → 句式模板 → 三元组 |
| **ActiveLearner** | `active_learner.py` | 信息获取 — KG→星图→搜索→用户 四层查询 |
| **OfflineLearner** | `offline_learner.py` | 离线学习 — BudgetContest 竞标 + 批判者高熵优先 |
| **DreamModule** | `dream_module.py` | 假说生成 — 类比/传递/反向质疑/co_text 涌现 |
| **MemoryConsolidation** | `memory_consolidation.py` | 记忆巩固 — 聚类 + 矛盾调和 + 冷边衰减 |
| **LanguageGenerator** | `language_generator.py` | 语言涌现 — 意图驱动三层排序 + 句式学习 |
| **MotherController** | `mother_controller.py` | 主循环 — 模块注入与调度 |

## 快速开始

```bash
pip install ddgs
cd src
python asteriamind_web.py
# 浏览器打开 http://localhost:8866
```

**API 端点**: `POST /api/talk` (对话) | `GET /api/reflect` (自我评估 + 权重) | `GET /api/health` (系统健康)

```
✅ STEP 1: 单图合并 — co_text 进主库 (597万边, 198MB)
```
